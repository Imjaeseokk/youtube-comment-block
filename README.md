# YouTube Comment Block · 댓글 잠시 멈춤

**영상 먼저. 내 생각 먼저.**

유튜브 영상 아래 댓글을 기본으로 가리고, “정말 댓글을 보시겠습니까?”를 묻는 Chrome Manifest V3 확장 프로그램입니다. 짧은 질문과 출처 있는 연구 안내가 습관적으로 댓글을 여는 순간에 여유를 더합니다.

## 사용 흐름

1. 영상 페이지에 들어가면 댓글은 첫 화면이 그려지기 전부터 가려집니다.
2. 댓글 위치에 유튜브의 글꼴·색상·버튼 형태를 따르는 선택 영역이 나타납니다.
3. **영상에 집중하기**를 선택하면 작은 안내만 남습니다.
4. **예, 댓글 보기**를 선택하면 해당 영상의 댓글을 표시합니다.
5. **다시 숨기기**로 되돌릴 수 있습니다. 다음 영상이나 뒤로 가기에서는 다시 동의를 묻습니다.

선택은 현재 페이지의 메모리에만 존재합니다. 영구적인 “항상 댓글 보기” 설정이나 자동 해제는 없습니다. 일반 영상 페이지의 댓글과 댓글 측면 패널을 지원합니다. Shorts, 모바일 사이트, 라이브 채팅은 현재 범위에 포함하지 않습니다.

## Chrome에 설치

빌드 과정 없이 `extension/` 폴더를 바로 설치할 수 있습니다.

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 클릭합니다.
4. 이 프로젝트의 `extension` 폴더를 선택합니다.
5. 이미 열려 있던 유튜브 탭은 새로고침합니다.

업데이트 후에는 확장 프로그램 화면에서 새로고침한 뒤 유튜브도 새로고침하세요. Chrome 웹 스토어 등록은 아직 진행하지 않았습니다.

## 로컬 화면 미리보기

Python 3만 있으면 실행됩니다.

```sh
python3 scripts/preview.py
```

브라우저에서 `http://127.0.0.1:4173/watch?v=example-video`를 엽니다. 확장 프로그램의 실제 CSS와 JS를 사용하는 유튜브 형태의 샘플 화면입니다. 테마, 다음 영상, 측면 댓글, 한국어·영어를 전환할 수 있습니다. 실제 유튜브에서 확장 프로그램을 설치한 검증과는 별개입니다.

## 개발 및 검증

Node.js 20 이상과 npm이 필요합니다. 배포 파일에는 JavaScript 라이브러리나 원격 코드가 포함되지 않습니다.

```sh
npm ci
npm run check
npm test
npm run assets:check
npm run package
```

테스트는 DOM 환경에서 첫 가리기, 명시적 동의, 재차 가리기, 영상 전환·뒤로 가기, 지연 삽입, 측면 패널, 언어 변경을 검증합니다. 배포 ZIP은 `dist/youtube-comment-block-0.1.0.zip`에 생성되며 GitHub에서 받을 수 있도록 `release/0.1.0/`에도 보관합니다. 같은 폴더의 `youtube-comment-block-store-kit-0.1.0.zip`에는 등록 문항·설명·개인정보처리방침 초안·스토어 이미지·아이콘 후보가 함께 들어 있습니다.

## Chrome 웹 스토어 등록 준비

- [등록 항목과 답변](docs/store/submission.ko.md): 한국어·영어 설명, 단일 목적, 호스트 접근 사유, 로컬 데이터 처리 공개, 원격 코드, 심사 테스트 안내.
- [등록 이미지 목록](assets/store/README.md): 128px 스토어 아이콘, 1280×800 스크린샷 5장과 영어 1장, 작은 프로모션·마키 이미지.
- [아이콘 후보 비교](assets/branding/gallery.html): 흑백 말풍선 + 빨간 금지 표시, 투명 배경 후보 5개. 각 SVG와 PNG 7개 크기 포함.
- `npm run assets -- 04`: 01–05 후보 선택 및 PNG·프로모션 재생성. 사용자가 선택한 04를 적용함. 04의 말풍선은 이전 시안보다 약 13% 더 줄이고, 금지 표시 원·사선 굵기는 34에서 38로 약 12% 더 늘렸음. 인수 없이 실행하면 현재 선택을 유지함.
- `npm run assets:check`: 이미지 형식·규격·알파 채널·투명 여백·로고 구성 검증.

등록 이미지의 UI는 실제 콘텐츠 스크립트를 실행한 로컬 샘플 캡처이며, 실사이트 설치 검증과 구분됩니다. 공개 개인정보처리방침은 [한국어](https://imjaeseokk.github.io/youtube-comment-block/privacy.html)·[영어](https://imjaeseokk.github.io/youtube-comment-block/privacy-en.html)로 제공하며 운영자명과 문의 이메일을 포함합니다. 실제 Chrome에서의 YouTube 설치 점검은 제출 전에 필요합니다. 아직 Chrome 웹 스토어에 등록하거나 심사를 신청하지 않았습니다.

## 연구 안내의 원칙

- [Muchnik, Aral & Taylor (2013), Science](https://doi.org/10.1126/science.1240466): 소셜 뉴스 사이트에서 초기 평가를 무작위로 조작한 실험. 이전 평가가 이후 평가 행동에 영향을 주었습니다.
- [Anderson et al. (2014), JCMC](https://doi.org/10.1111/jcc4.12009): 나노기술 기사에 대한 무례한 댓글 노출이 기존 성향에 따라 위험 인식을 양극화한 실험.

연구 소개에는 원문 링크, 맥락, 일반화의 한계를 표시합니다. 일상적인 성찰 문구는 연구 결과와 다른 제목으로 표시합니다. “팝콘 브레인”을 진단명처럼 쓰거나 이 확장 프로그램의 건강 개선 효과를 주장하지 않습니다. 같은 영상에서는 동일한 안내가 유지되며, 영상 ID에 따라 네 가지 안내 중 하나가 선택됩니다.

## 개인정보와 권한

댓글 본문, 영상 제목, 시청 기록을 읽거나 저장하지 않습니다. 현재 URL의 영상 ID는 동의 범위와 안내 선택에만 메모리에서 사용됩니다. 서버, 분석 도구, 쿠키, 로컬 저장소, 외부 폰트 호출이 없습니다. 연구 링크는 사용자가 눌렀을 때만 열립니다.

콘텐츠 스크립트는 `https://www.youtube.com/*`에서 실행됩니다. 홈에서 영상으로 이동하는 유튜브의 페이지 전환을 처리하기 위한 범위입니다. 콘텐츠 스크립트 실행에 따라 Chrome은 유튜브 페이지에 대한 접근 권한을 표시할 수 있습니다. 추가적인 `tabs`, `storage`, `scripting` 권한은 요청하지 않습니다.

댓글의 화면 노출을 가리는 방식입니다. 유튜브의 댓글 요청이나 다운로드 자체를 차단하지 않습니다. 유튜브 내부 DOM이나 이벤트가 바뀌면 대응이 필요할 수 있습니다. YouTube가 제공하거나 승인한 기능은 아니며 독립적인 확장 프로그램입니다.

## 프로젝트 구조

- `extension/`: 설치 가능한 확장 프로그램
- `preview/`: 실제 콘텐츠 스크립트를 사용하는 샘플 화면
- `tests/`: 동작 및 매니페스트 검증
- `scripts/`: 로컬 미리보기 서버와 ZIP 생성
- `docs/`: 기획, 연구 출처, 실제 브라우저 점검 목록과 스토어 등록 문서
- `assets/`: 아이콘 후보 원본·PNG 내보내기와 스토어 이미지
- `release/`: 제출용 ZIP, 자료 묶음 및 SHA-256 체크섬

GitHub 저장소: [Imjaeseokk/youtube-comment-block](https://github.com/Imjaeseokk/youtube-comment-block) (비공개). 소스·문서·에셋·제출 ZIP을 함께 관리합니다.
