# 아이콘 제작 기준

2026-10-17 사용자 요청을 기준으로 새 SVG 원본과 PNG 내보내기를 제작했다. 이미지 생성 스킬의 적용 범위를 확인했고, 정확한 선 개수와 기하 구조를 요구하는 단순 아이콘이므로 벡터 제작 방식을 사용했다. 이미지 생성 모델 또는 외부 이미지 API는 사용하지 않았다.

- 검정(#000000)·흰색(#FFFFFF) 말풍선과 유튜브 계열 빨강(#FF0033)의 금지 표시.
- 라운드가 있는 말풍선 안에 서로 길이가 다른 수평선 정확히 3개.
- 말풍선 위에 원형 테두리와 대각선으로 구성한 금지 표시. 공식 YouTube 재생 로고를 복제하지 않음.
- 말풍선 자체는 정면·수평. 회전, 원근, 그림자, 그라디언트, 바깥 배경 없음.
- 검정 채움형의 흰 테두리는 어두운 화면에서 윤곽을 유지하기 위한 구조적 테두리이며 광원·그림자가 아님.
- 후보마다 비율·채움·금지 표시 배치를 달리함. 별도 캐릭터·장식·추가 색 없음.

추가 피드백 “코멘트 말풍선 크기 조금 줄이고 블럭은 두께 키워”를 다섯 후보 모두에 적용: 말풍선과 내부 선은 중심 기준 90%로 축소, 금지 표시의 원과 사선 굵기는 기존의 135%로 확대.

후보 번호는 01 기본 윤곽형, 02 검정 채움형, 03 넓은 말풍선형, 04 중앙 금지형, 05 둥근 말풍선형이다. 사용자가 04를 선택했고 패키지와 스토어 이미지에 적용했다. 04만 말풍선 비율을 0.90에서 0.78로 약 13% 추가 축소하고 금지 표시 원·사선 굵기를 34에서 38로 약 12% 추가 확대했다. 다른 후보의 형태는 유지한다.

각 후보의 원본은 `candidates/candidate-XX/icon.svg`, PNG는 16/32/48/128/256/512/1024px다. 128px 아이콘은 96px 영역 안에 그림을 배치하고 사방 16px을 투명하게 둔다. PNG의 가장자리 안티앨리어싱에서 생기는 중간 색은 렌더링 결과이며 SVG의 색상은 위 세 가지뿐이다.

`npm run assets -- 04`로 재생성한다. 인수를 생략하면 저장된 선택을 유지한다. SVG 기하 정보와 최종 선택 상태는 `scripts/build-assets.cjs`, `selection.json`에서 확인할 수 있다. 모든 파일은 프로젝트 안에 보관되며 갤러리의 체크무늬는 투명도 표시일 뿐 파일에 포함되지 않는다.
