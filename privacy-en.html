YouTube Comment Block

Privacy Policy

How the extension processes information on your device to show comments only when you choose.

Effective October 17, 2026 · Version 0.1.0

Temporary on-device processingNo developer-server transmissionNo extension analytics

Purpose and operator

YouTube Comment Block hides comments until the user explicitly chooses to view them for the current video. It is an independent browser extension operated by Jaeseok Heo (Imjaeseokk), not affiliated with or endorsed by YouTube or Google.

Information processed temporarily on the device

  • The path and video ID in the current www.youtube.com page URL identify watch pages, reset consent when videos change, and select a prompt. The extension does not access the browser’s history database.
  • Page structure (DOM) for comment containers and the comments side panel is used to apply visibility and insert the choice UI. Comment text, authors and video titles are not extracted into records.
  • The choice to show or hide comments exists only as temporary page memory. A new video, reload or departure requires a fresh choice.
  • Existing browser/page language and YouTube theme settings determine the displayed language and colors.

This information is processed locally only as needed for the stated functionality. The extension does not collect account details, email addresses, passwords, authentication cookies or tokens, payment information, location or health information. It does not create keystroke, scrolling or mouse-movement analytics logs.

Storage, transmission and sharing

The extension does not write user data to cookies, localStorage, IndexedDB, Chrome storage or developer servers. It does not accumulate video IDs or choices into a history. There are no analytics SDKs, ad SDKs, remote code or developer API servers. User data is not sold, shared, or used for advertising, profiling, creditworthiness or lending.

If you separately contact support, the contact details and message you choose to provide are handled only as necessary to respond. Do not send passwords, cookies, authentication tokens or unnecessary personal information.

External sites

Research links open an external publisher or DOI page only when clicked. The extension does not append video IDs or comments to those links. External sites and YouTube process data under their own policies. This extension does not block YouTube’s comment downloads or YouTube’s own data processing.

Your choices

You can hide comments again or disable/uninstall the extension in Chrome at any time. No user data is persistently stored by the extension, so there is no separate stored-data deletion process. No extension account is required.

Changes and contact
