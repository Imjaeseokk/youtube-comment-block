# 실제 Chrome 점검 목록

## 로컬 검증 결과 (2026-10-11)

10개 DOM 테스트와 JavaScript 구문 검사를 통과했다. 실제 브라우저의 로컬 샘플 화면에서 동의 전 숨김, “예, 댓글 보기” 후 표시, 다음 영상에서 재차 숨김, 테마 전환을 확인했다. 밝은 테마와 어두운 테마 스크린샷은 `screenshots/`에 저장했다. 설치용 ZIP을 생성하고 포함 파일을 확인했다.

실제 YouTube 사이트에 확장 프로그램을 설치한 검증은 아직 수행하지 않았다.

## 등록 자료 검증 (2026-10-17)

기존 동작 테스트 10개와 JavaScript 구문 검사를 통과했다. 아이콘 후보 5개의 SVG 구성(길이가 다른 선 3개, 단일 금지 표시, 회전·배경·그림자 없음), PNG 35개 및 설치 아이콘의 알파 채널·투명 여백, 스토어 이미지 9개의 규격을 확인했다. 스토어 아이콘 1개, 프로모션 2개, 스크린샷 6개가 포함된다. 한국어·영어 로케일의 이름·설명 길이를 확인했다.

말풍선 10% 축소·금지 표시 선 굵기 35% 확대 피드백을 다섯 후보 모두에 반영했다. 이후 사용자가 후보 04를 선택했다. 말풍선을 이전보다 약 13% 추가 축소하고 금지 표시 선을 34에서 38로 약 12% 추가 확대해 설치 아이콘과 등록 이미지에 적용했다. 등록 문서의 운영자명·연락처를 채웠고 공개 개인정보처리방침은 GitHub Pages에서 한국어·영어로 제공한다. 실사이트 설치 검증 상태는 위와 동일하다.

## 개인정보처리방침 배포 확인 (2026-10-17)

GitHub Pages 실행 `39022764377`이 성공했다. 한국어·영어 정책, CSS, 아이콘, 진입 페이지의 HTTPS 응답은 모두 HTTP 200이며 배포 원본과 바이트 단위로 일치했다. 실제 공개 페이지에서 로그인 없이 한국어·영어 전환을 확인했다. 배포 내역은 `docs/store/github-pages.md`, 화면은 `docs/store/privacy-page-preview.jpg`에 기록했다.

## 설치 후 확인할 항목

자동 DOM 테스트와 로컬 미리보기로 검증할 수 없는 항목은 실제 Chrome에서 확장 프로그램을 설치한 뒤 확인한다.

- 일반 영상 URL 직접 진입: 느린 네트워크에서도 댓글 본문이 먼저 보이지 않는지 확인
- 홈·검색·재생목록에서 영상으로 이동: 댓글 선택 영역이 나타나는지 확인
- 댓글 열기 후 다음 영상·브라우저 뒤로/앞으로·자동 재생: 다시 가려지는지 확인
- 아래로 스크롤하여 댓글 지연 삽입 유도: 선택 영역 중복이나 누락 확인
- 댓글 다시 숨기기: 댓글 입력과 답글을 포함한 전체 영역이 가려지는지 확인
- 댓글 측면 패널: 열기·닫기·다른 패널로 전환 시 정상 배치 확인
- 밝은 테마·어두운 테마·영화관 모드·좁은 창: 글자와 버튼 대비 및 배치 확인
- 댓글 비활성화 영상: 유튜브 안내를 보려면 동의가 필요한 현재 동작 확인
- 키보드: Tab 이동, Enter/Space 선택, 펼침 목록, 연구 링크 확인
- 한국어·영어 유튜브: 안내 언어 확인
- Shorts와 라이브 채팅: 현재 지원 범위 밖이므로 별도 기능으로 기록

콘텐츠 스크립트는 유튜브 비공개 DOM 구조와 `yt-navigate-*` 이벤트를 이용한다. 유튜브 변경 후에는 이 점검을 반복해야 한다.
