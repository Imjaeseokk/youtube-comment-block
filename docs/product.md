# 제품 기준

## 목적

습관적인 댓글 열람, 타인의 해석을 먼저 접하는 데서 오는 편향, 불필요한 감정 소모를 줄이고 싶은 이용자에게 댓글을 읽을지 직접 선택하는 순간을 제공한다.

## 경험

댓글 영역 안에서 선택한다. 영상을 덮는 모달이나 알림은 사용하지 않는다. 댓글 수나 미리보기로 호기심을 자극하지 않는다. 기본 행동은 영상에 집중하기다. 사용자가 원하면 즉시 댓글을 볼 수 있으며, 시간 제한이나 죄책감을 주는 문구를 두지 않는다.

유튜브의 테마 변수, 12px 모서리, 둥근 버튼, 기본 글꼴을 사용한다. 어두운 테마, 좁은 화면, 키보드 이동을 지원한다. 제품 이름과 독립 확장 프로그램이라는 설명은 팝업에 표시한다.

## 동의 범위

현재 영상의 일반 댓글과 측면 패널에 적용한다. 영상 이동, 뒤로 가기, 새로고침에는 새 동의를 요구한다. 라이브 채팅과 Shorts는 별도로 설계해야 하므로 첫 버전에서 제외한다.

## 안내 문구

2개의 연구 안내와 2개의 성찰 질문을 사용한다. 연구에는 저자·학술지·연도·원문 링크·조건·한계를 담는다. 의학적 진단, 확장 프로그램의 효과 수치, 댓글 전체를 유해하다고 단정하는 문장은 사용하지 않는다.

## 후속 후보

실제 설치 점검과 다양한 유튜브 레이아웃에 대한 대응을 먼저 진행한다. 이후 Shorts, 영어 팝업, 사용자 선택형 안내 문구, 웹 스토어 배포를 검토할 수 있다. 익명 지표라도 수집이 필요해지면 제품 정책과 사용자의 선택 흐름을 먼저 설계한다.
