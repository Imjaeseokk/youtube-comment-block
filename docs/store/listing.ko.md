# YouTube Comment Block

## 짧은 설명

댓글을 보기 전에 한 번 멈추세요. 영상에 먼저 집중하고, 원할 때만 댓글을 여세요.

## 상세 설명 — 아래부터 복사

영상 먼저. 내 생각 먼저.

YouTube Comment Block은 유튜브 영상의 댓글을 기본으로 가리고, 내가 선택할 때만 보여주는 확장 프로그램입니다.

댓글을 보지 않으려고 했는데 어느새 읽고 있거나, 영상을 다 보기도 전에 다른 사람의 반응부터 확인한 적이 있나요? 댓글 영역에 나타나는 작은 질문이 그 익숙한 행동에 잠깐의 여유를 더합니다.

■ 어떻게 사용하나요?
• 댓글 위치에 “정말 댓글을 보시겠습니까?”라는 안내가 나타납니다.
• “영상에 집중하기”를 선택하면 댓글을 가린 채로 둘 수 있습니다.
• “예, 댓글 보기”를 선택하면 현재 영상의 댓글만 열립니다.
• 열린 댓글은 “다시 숨기기”로 되돌릴 수 있습니다.
• 다음 영상에서는 다시 선택합니다. 한 번의 선택으로 모든 영상의 댓글이 열리지 않습니다.

■ 단순한 숨김에서 한 걸음 더
댓글을 열기 전에 내 생각을 돌아보는 짧은 질문, 또는 다른 사람의 평가와 거친 댓글이 인식에 미칠 수 있는 영향을 다룬 연구 안내를 보여줍니다. 연구 안내에는 출처 링크와 연구의 맥락·한계가 함께 있습니다. 영상마다 네 가지 안내 중 하나가 선택됩니다.

■ 유튜브 화면과 자연스럽게
영상을 덮는 팝업 대신 댓글 위치에 선택 영역을 표시합니다. 유튜브의 밝은 테마와 어두운 테마에 맞춰 동작하며, 한국어·영어 안내와 댓글 측면 패널을 지원합니다.

■ 계정 없이, 기기 안에서
확장 프로그램 자체의 회원가입, 광고, 구독, 분석 도구가 없습니다. 현재 영상 ID와 댓글 영역의 구조는 기능 수행을 위해 기기 안에서만 일시적으로 처리합니다. 댓글 본문이나 브라우저 방문 기록을 추출해 저장하지 않으며, 개발자 서버로 데이터를 전송하지 않습니다. 연구 링크는 직접 눌렀을 때만 외부 페이지로 열립니다.

■ 지원 범위
데스크톱 Chrome의 www.youtube.com 일반 영상 페이지를 지원합니다. Shorts, 라이브 채팅, 모바일 유튜브 앱·모바일 사이트는 지원하지 않습니다. 댓글의 화면 표시를 가리는 기능으로, 유튜브의 댓글 다운로드 자체를 차단하지는 않습니다. 설치 후 이미 열려 있던 유튜브 탭은 새로고침해 주세요.

이 확장 프로그램은 YouTube 또는 Google이 제작·제휴·승인한 제품이 아닙니다. 연구 안내는 정보 제공용이며 건강 상태를 진단하거나 치료 효과를 보장하지 않습니다.
