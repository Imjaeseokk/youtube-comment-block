## 2. 개인정보 보호 관행

### 단일 목적 설명 / Single purpose description

유튜브 영상 페이지의 댓글을 기본으로 가리고, 사용자가 현재 영상에서 직접 댓글 보기를 선택한 경우에만 표시하여 습관적인 댓글 열람을 잠시 멈추도록 돕습니다. 댓글 선택 영역의 성찰 질문과 출처 있는 연구 안내는 이 선택을 돕는 부가 설명입니다.

### 호스트 접근 권한 사유 / Host permission justification

`https://www.youtube.com/*`에서 댓글 영역을 찾고 숨김·표시 CSS와 선택 UI를 적용하기 위해 콘텐츠 스크립트를 실행합니다. 유튜브는 홈·검색에서 영상으로 이동할 때 전체 문서를 다시 불러오지 않으므로, 영상 경로만이 아니라 같은 호스트의 페이지에서 이동 이벤트를 감지해야 합니다. 현재 URL의 영상 ID는 영상별 선택을 초기화하고 안내 문구를 선택하는 데만 메모리에서 사용합니다. 다른 사이트에는 실행되지 않으며 댓글 본문이나 시청 기록을 추출·저장·전송하지 않습니다.

매니페스트에 별도의 `host_permissions` 또는 `permissions` 배열은 없습니다. 대시보드가 콘텐츠 스크립트의 `matches`에서 호스트 접근 사유를 요청할 경우 위 답변을 사용합니다. `tabs`, `storage`, `scripting`, `history`, `webRequest`, `cookies`, `activeTab` 권한 사유는 해당하지 않습니다.

### 원격 코드 사용 여부 / Are you using remote code?

**아니요. 원격 코드를 사용하지 않습니다.**

실행되는 JavaScript, CSS, SVG 도형 정보, 연구 안내 문구와 아이콘은 모두 제출 ZIP에 포함됩니다. 원격 스크립트, 원격 스타일시트, CDN, 동적 코드 다운로드, `eval`, AI API 호출은 없습니다. 사용자가 직접 선택하는 DOI 링크는 외부 논문 페이지를 새 탭으로 여는 링크이며 확장 프로그램 실행 코드가 아닙니다.

### 데이터 이용 확인 사항 / Certifications

현재 구현을 기준으로 다음 세 항목을 확인할 수 있습니다.

- 허용된 경우를 제외하고 사용자 데이터를 제3자에게 판매하거나 이전하지 않습니다.
- 확장 프로그램의 단일 목적과 무관한 용도로 데이터를 사용하거나 이전하지 않습니다.
- 신용도 판단 또는 대출 목적으로 데이터를 사용하거나 이전하지 않습니다.

제출 시 개인정보처리방침과 구현이 일치하는지 확인한 뒤 개발자가 인증합니다.

## 4. 심사 담당자에게 전달할 테스트 안내

테스트 계정이나 라이선스 키가 필요하지 않습니다. Chrome에 확장 프로그램을 설치한 뒤, 댓글이 활성화된 일반적인 `https://www.youtube.com/watch?v=...` 영상을 엽니다. 기존 유튜브 탭은 설치 후 새로고침합니다.

1. 댓글 위치로 스크롤합니다. 댓글 본문 대신 “정말 댓글을 보시겠습니까?”라는 선택 영역이 표시됩니다.
2. “영상에 집중하기”를 누르면 댓글이 가려진 상태로 작은 안내만 남습니다.
3. “댓글 보기 선택”을 누르면 질문으로 돌아옵니다. 이 버튼만으로 댓글이 공개되지는 않습니다.
4. “예, 댓글 보기”를 누르면 현재 영상의 댓글이 표시됩니다.
5. “다시 숨기기”로 다시 가릴 수 있습니다.
6. 다른 영상으로 이동하거나 뒤로 가기를 하면 새 동의를 요구합니다.
7. 연구 안내가 선택된 영상에서는 “연구와 출처 보기”에서 연구 맥락·한계·DOI 링크를 확인할 수 있습니다. 모든 영상에 연구가 나오는 것은 아니며 네 가지 안내 중 하나가 영상 ID에 따라 선택됩니다.
8. 유튜브의 밝은 테마·어두운 테마와 한국어·영어 안내를 확인할 수 있습니다.

일반 영상의 댓글과 댓글 측면 패널이 대상입니다. Shorts, 모바일 앱·모바일 사이트, 라이브 채팅은 지원 대상이 아닙니다. 댓글 화면을 가리는 방식이며 유튜브의 댓글 다운로드 요청 자체를 차단하지는 않습니다.

## 패키지를 다시 올릴 때

이미 업로드한 패키지를 교체할 때는 `extension/manifest.json`의 `version`을 이전보다 높이고 다시 패키징한다. 제목·아이콘만 바꿔도 패키지를 다시 업로드하면 버전을 올려야 한다. ZIP 파일명만 바꾸는 것으로는 버전이 바뀌지 않는다. 현재 제출 파일은 `release/0.1.1/youtube-comment-block-0.1.1.zip`이다. `store-kit` ZIP은 자료 묶음이므로 확장 프로그램 패키지 업로드에 사용하지 않는다.

공식 안내: https://developer.chrome.com/docs/webstore/update#upload_an_updated_zip_file
