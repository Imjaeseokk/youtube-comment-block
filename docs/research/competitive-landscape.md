# 기존 확장 프로그램 조사

조사일: 2026-10-12. 웹 스토어·개발사 설명 기준이며 직접 설치 비교는 수행하지 않았다. 사용자 수·별점과 같은 변동 수치는 생략했다.

| 제품 | 겹치는 부분 | 설명에서 확인된 차이 |
| --- | --- | --- |
| [Shut Up: Comment Blocker](https://chromewebstore.google.com/detail/shut-up-comment-blocker/oklfoejikkmejobodofaimigojomlfim) | 댓글 기본 숨김과 버튼으로 다시 표시, 부정적인 댓글 경험에서 벗어나려는 목적 | 사이트별 표시 선택을 기억함. 영상별 질문이나 연구 안내는 설명에 없음 |
| [Hide Comments Everywhere](https://chromewebstore.google.com/detail/hide-comments-everywhere/bmhkdngdngchlneelllmdennfpmepbnc) | 유튜브 등 여러 사이트에서 댓글 숨김·다시 표시 | 도메인별 토글, 허용·차단 목록 중심 |
| [Hide YouTube Comments](https://chromewebstore.google.com/detail/hide-youtube-comments/bgeoifdgcnafonfffcmlcjbeldhocnpd) | 유튜브 전체 댓글 숨김 | 설명상 단순 숨김 기능 |
| [Unhook](https://chromewebstore.google.com/detail/unhook-remove-youtube-rec/khncfooichmfjbepaaaebmommgaepoid) | 댓글·추천 영상·Shorts 등 숨김 | 유튜브 전체의 방해 요소 설정이 중심 |
| [Comment Shield](https://getcommentshield.com/index-en.html) | 공격적인 댓글을 가리고 선택해서 공개, 다시 숨기기, 휴식 알림 | 개별 악성 댓글 필터링 중심. 전체 댓글 숨김 모드와 별도 정신적 부담 설명 페이지도 있음 |
| [Mindful Noting](https://chromewebstore.google.com/detail/mindful-noting/moagbfaaknaglbjikfcdankpgaiglmab) | 유튜브 영상마다 소비 전 의도·감정과 소비 후 성찰을 유도 | 댓글 열람보다 콘텐츠 소비 전체를 대상으로 함 |

댓글을 기본으로 숨기고 버튼으로 여는 기능과 댓글 스트레스를 줄이려는 문제의식은 기존 제품에도 있다. 제품의 차이를 검토할 조합은 댓글을 열려는 순간의 질문, 현재 영상에만 적용되는 동의, 특정 연구의 출처·조건·한계 안내, 댓글 위치에 통합된 UI다. 조사 범위에서 이 조합을 그대로 설명하는 제품은 확인하지 못했지만 최초라는 주장은 하지 않는다.
